# Результаты проверки производительности

Дата проверки: 18 сентября 2026 года.

## Окружение

- Node.js 24.19.0; проект сохраняет заявленную совместимость с Node.js 18+.
- Синтетический сценарий запускается командой `npm run test:load`.
- Интеграционный тест поднимает сервер на свободном локальном порту и подключает два реальных Socket.IO-клиента.

## Автоматическая проверка

Команда `npm test` завершилась успешно: 21 проверка, 0 ошибок.

Проверены нормализация общего вида, ревизии, ограничение истории, преобразование вида для разных размеров окна, ограничение частоты, объединение перерисовок, индекс объектов, пакетирование текста, масштабирование изображений, HTML-элементы управления и взаимодействие двух Socket.IO-клиентов.

## Нагрузочный сценарий

Сценарий обработал смешанную последовательность из 882 операций:

- 600 карандашных путей;
- 120 законченных серий ввода текста;
- 150 фигур;
- 12 описаний изображений;
- 1000 входных изменений общего вида;
- 1000 запросов перерисовки в одном кадре.

## Ограничения результатов

Синтетический тест подтверждает работу ограничителей, но не заменяет длительный замер FPS и памяти в браузере на целевом слабом сервере. Облачный браузер проверки не получил доступ к локальному адресу сборочной среды, поэтому окончательную визуальную проверку двух окон следует повторить после публикации или на целевом сервере. Интеграция двух участников на уровне Socket.IO проверена автоматически.
