# Онлайн-доска

Небольшая совместная онлайн-доска на Node.js, Socket.IO и Fabric.js.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

После запуска откройте `http://localhost:3000`. Один участник создаёт комнату и передаёт второму её код или ссылку.

## Проверка

```bash
npm test
npm run test:load
```

## Управление

- Колесо мыши меняет общий масштаб для всех участников.
- Инструмент «рука» или зажатый пробел перемещает общий вид доски.
- Кнопка «Вид» возвращает общий масштаб к 100% и центрирует доску в начале координат.
- «Отменить»/`Ctrl+Z` отменяет последнее общее действие.
- «Повторить»/`Ctrl+Y` или `Ctrl+Shift+Z` возвращает отменённое действие.
- Палитра справа снизу постоянно доступна; последний элемент позволяет выбрать произвольный цвет.
- Кнопка «Курсор» показывает вашу позицию другим участникам.

## Ограничения

Данные комнаты хранятся в оперативной памяти. Когда выходит последний участник или сервер перезапускается, состояние комнаты удаляется. Серверная история ограничена 200 действиями и 25 МБ на комнату.
